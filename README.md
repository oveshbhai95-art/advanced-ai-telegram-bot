# advanced ai telegram bot

telegram bot powered by openai (chatgpt + dall-e)  
features: ai chat, image generation, code gen, translation, summarization, buttons, welcome image, conversation memory.

all replies in small caps style (except commands like /start).

## setup
1. clone repo
2. cp .env.example .env → fill BOT_TOKEN and OPENAI_API_KEY
3. pip install -r requirements.txt
4. python main.py

## deploy
- render.com / railway.app pe github connect kar deploy kar
- health endpoint add kar (/ping return 200) for uptime
- use hetrixtools or betterstack for free 1-min pings to keep alive
